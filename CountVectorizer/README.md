# CountVectorizer - Text Vectorization using Scikit-learn

## Overview

This notebook demonstrates how to convert text data into numerical features using **CountVectorizer** from Scikit-learn. It covers the fundamentals of the **Bag of Words (BoW)** model and explores the most commonly used parameters for text preprocessing.

## Objectives

- Understand the Bag of Words technique
- Convert text documents into numerical vectors
- Learn how CountVectorizer builds a vocabulary
- Explore important CountVectorizer parameters
- Transform new text using the learned vocabulary
